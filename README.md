# medlemssystem

Statisk side for medlemssystem.no (GitHub Pages).

## Logo

Den offisielle logoen ligger i `assets/img/logo/`. Alle filer er utledet fra SVG-mastrene.

| Fil | Bruk |
|---|---|
| `medlemssystem-logo.svg`, `medlemssystem-logo-4000.png` | Horisontal logo på lys bakgrunn |
| `medlemssystem-logo-hvit.svg`, `medlemssystem-logo-hvit-4000.png` | Horisontal logo på mørk bakgrunn |
| `medlemssystem-ikon-kvadrat.svg`, `-2048.png`, `-512.png`, `-192.png` | Bare ikonet (avrundet firkant): favicon, app-ikon |
| `medlemssystem-ikon-kvadrat-hvit.svg`, `-hvit-2048.png` | Ikonet til mørk bakgrunn |
| `medlemssystem-ikon-kvadrat-fullbleed.svg`, `-1024.png`, `-512.png` | Kvadrat uten avrunding: profilbilde i sosiale medier, maskerbart app-ikon |

Regler:
- Farger: mørkeblå `#0b2252` (firkant, ord), flaggrød `#e71111` (midterste person), hvit.
- Skrift: Public Sans Bold. Ikke tegn ordet på nytt, bruk filene.
- Minste størrelse: 24 px høyde for hele logoen, 16 px for ikonet.
- Frisone: minst en halv firkant (50 % av ikonets høyde) på alle sider.
- Ikke strekk, roter, skift farger eller legg på skygge.
